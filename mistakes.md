- 2026-11-15: In ticket 06 my first clamp() type scale had rem minimums high enough that the stack didn't fit a 568×320 landscape phone, and I'd put `overflow: hidden` only on html/body, so tabbing to a clipped link still scrolled the page. - 2026-11-16: In ticket 15 I first assumed `renderer.setAnimationLoop(null)` stops three's frame loop. Read the library's loop code (`renderers/common/Animation.js`) before relying on a stop call.

- 2026-11-16: In ticket 17 I first read `window.location.hash` at a composable's module top level. The module also loads during SSR/prerender, where `window` doesn't exist. Read browser globals inside functions that only run on the client (onMounted, idle callbacks).
