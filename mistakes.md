# Mistakes


- 2026-11-12: Added orbiting satellite spheres and breathing/drift to the corner metaballs without being asked, to "show off" the metaball merge. Build only what's described; effects come later when requested.
- 2026-11-13: Asked the /init-repo idea question as plain text. Always ask through the AskUserQuestion input tool.
- 2026-11-15: Put an HTML comment at the top of a Vue template, which made the component a fragment root, so `aria-hidden` wasn't on the wrapper's root and the test failed. Keep template comments inside the root element, or put them in the script.
- 2026-11-15: In ticket 13 I only sent pointer moves through the intro-stroke interrupt and forgot the brush lifts that `listenForBrushPointer` fires on pointerdown/up, so a tap broke the intro without stopping it. When a pointer listener has more than one callback, route all of them through the takeover logic.
- 2026-11-15: In ticket 06 my first clamp() type scale had rem minimums high enough that the stack didn't fit a 568×320 landscape phone, and I'd put `overflow: hidden` only on html/body, so tabbing to a clipped link still scrolled the page. For shrink-to-fit, add up the stack's height at the smallest target viewport before picking minimums, and clip the content block itself.
- 2026-11-15: In ticket 06 I gave `<main>` `max-block-size: 100%` + `overflow: clip` without remembering Nuxt wraps the app in an auto-height `<div id="__nuxt">`, so the percentage resolves to none and nothing is clipped. Check the real DOM chain (`#__nuxt`) before relying on percentage heights.
- 2026-11-15: Told the owner @nuxt/fonts needs `processCSSVariables: true` to read `--font-body`; its default (`font-prefixed-only`) already reads `--font-*` properties. Check the module's defaults in node_modules before stating a config requirement.
- 2026-11-16: In ticket 15 I first assumed `renderer.setAnimationLoop(null)` stops three's frame loop. In r187 it only drops the callback. `Renderer.render()` restarts an internal rAF (`_animation`) that keeps ticking, so the "sleeping" loop and the still frame would still wake the page every frame. Read the library's loop code (`renderers/common/Animation.js`) before relying on a stop call.
- 2026-11-15: In ticket 14 I wrote the AskUserQuestion option "Unblended focus ring" as "a new ticket", even though focus visibility was a requirement of the ticket I was building. Before calling something a follow-up, check whether the current ticket already asks for it, and say so in the question.
- 2026-11-16: In ticket 16 I first moved the difference blend onto a hand-kept element list (`svg, h1, p, address, a`) but left the white blended text colour on the whole `.content-layer` group, so any element missing from the list would render white on paper. Keep a colour that only works under a blend on the same selector as the blend, and prefer a structural rule (`:not(:has(a))`) to a hand-kept tag list.
- 2026-11-16: In ticket 17 I first read `window.location.hash` at a composable's module top level. The module also loads during SSR/prerender, where `window` doesn't exist. Read browser globals inside functions that only run on the client (onMounted, idle callbacks).
- 2026-11-16: In ticket 17 I lifted the brush on the panel's `pointerover`. That bubbles from every child, and the lift also stopped the intro stroke, so any hover inside the panel cancelled a replay the panel had just started. To react to entering an element, use `pointerenter`, and check what else a reused callback does.
- 2026-11-16: In ticket 10 my slogan-or-description question didn't say which text would show on the page. The owner picked "split" and then found only one line under the h1. When a choice changes what visitors see, spell out the visible result in each option.
- 2026-11-16: In ticket 02 I again put an HTML comment at the top of a component's template (`LocaleSwitch.vue`), the same mistake logged on 2026-11-15, and only caught it after the tests passed. Re-read mistakes.md before writing a Vue template, and write component notes in the script.
- 2026-11-16: In ticket 03 my first share-image script for Windows PowerShell 5.1 had "única" typed in it. PS 5.1 reads a script without a BOM as ANSI, so the PNG said "Ãºnica". I also loaded the bold and regular TTFs into one PrivateFontCollection, and the regular slogan came out bold. In PS 5.1 scripts, write non-ASCII as `[char]0x..`, use one font collection per weight, and look at the output image before using it.
- 2026-11-16: In ticket 05 I took for granted that @nuxtjs/sitemap writes `/sitemap.xml`. With @nuxtjs/i18n and a prefix strategy it writes a sitemap index plus per-locale sitemaps, and `/sitemap.xml` turns into a redirect. The code review caught it. When a ticket names an output file, trace the module's code path for this exact config (here `sitemaps` and the i18n strategy) before calling the default good enough.
- 2026-11-16: In ticket 09 I set Netlify's publish dir to `.output/public` from the ticket without checking nitro's provider detection. On Netlify, `nuxt generate` picks the `netlify-static` preset, which writes to `dist/`, so the deploy would have found nothing to publish. Before writing hosting config, check which nitro preset the host's env selects (`nitropack/dist/presets/_resolve.mjs`) and where it writes.
